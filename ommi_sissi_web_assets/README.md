# Ommi Sissi web assets

## Use these in the app
- `ommi-sissi-logo.svg` — primary full logo; recommended for navbar/hero/footer.
- `ommi-sissi-logo.png` — 2048px transparent fallback.
- `ommi-sissi-icon.svg` — compact mark with the standalone `i` removed.
- `ommi-sissi-icon.png` — 1024px transparent fallback.
- `favicon.ico`, `favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png` — browser tab icons.
- `apple-touch-icon.png` — iOS.
- `icon-192.png`, `icon-512.png`, `site.webmanifest` — PWA/app icons.
- `brand-colors.css` — approved brand color variables.

## Alternate formats
- `.webp` — transparent lossless WebP.
- `*-cream.png` / `*-cream.jpg` — approved cream-background versions.
- `ommi-sissi-profile-1024.jpg` — square profile/social avatar asset.

## Palette
- Red `#C6462B`
- Dark brown `#2B2115`
- Olive `#6B6F3D`
- Cream `#F5EDE3`

The SVG files are clean vector traces designed for web use; the vintage grain from the presentation board has intentionally been removed so the mark stays crisp at small sizes.
